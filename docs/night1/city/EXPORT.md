# P1 City — browser city -> Unreal pipeline

> Homage fan game. Not an official Marvel, Sony or Insomniac game; no affiliation.

Everything under `/Game/City` and `/Game/Tests/City` is generated (Content/ is not committed, see `unreal/WebHomage/CONTENT.md`).

## Rebuild from scratch
1. `npx vite --port 5202 --host 127.0.0.1 --strictPort` (P1 dev port) and `tools/export/ue/launch_editor.sh` (P1 editor, MCP :8771,
   file job server `tools/export/ue/job_server.py` polling `_scratch/city/uejobs`; jobs via `tools/export/ue/uejob.py`).
2. `tools/export/build_city.sh` = `export_city.mjs` -> `prep_textures.py` -> `gen_shaders.mjs` -> `Scripts/build_city.py`
   (idempotent: `/Game/City` recreated, test maps reopened + emptied and repopulated).
3. `tools/export/capture_round.sh docs/night1/city/round-NN` = every view of `Scripts/city_shots.json` through `Scripts/run_game.sh`
   (offscreen `-game`, 1920x1080 and 3840x2160, screenshot at t=28 s, frame times 18-28 s).

## Exporter (`tools/export/export_city.mjs` + `collect_page.js`)
Runs the real browser city (`?shot=street`) in headless Chrome against the P1 dev server and dumps, for tiles
ix -1..1 / iz -2..0 (x -256..512, z -512..256: 8th / 6th / 5th Av, the Times-Square-like bowtie):
- `mesh/<kind>/<name>__t<ix>_<iz>.glb`: facade / detail / roofs / signage tiles whole; ground + Times Square meshes clipped
  to 256 m tiles (Sutherland-Hodgman with barycentric attribute interpolation). Positions relative to the tile centre.
- far ring: facade-LOD masses of tiles ix -4..3 / iz -8..4 outside the region (same facade material), so views do not end in a void.
- `proto/<pool>.glb` + `layout.json` `instances`: every distance-Pool item (street furniture, rooftop equipment, eztree trees).
- `layout.json`: streets, blocks, footprints (h, archetype), zip points, browser viewpoints. `collision.json`: BOX / CYL / RAMP / HF solids + fields.
- UV packing (glTF TEXCOORD_n = UE UV n): see the header of `export_city.mjs` (facade uses all 8 channels + vertex colour = tint / 2).

## Transform
glTF frame = browser frame (metres, +x east, +y up, -z north). UE Interchange glTF: UE = (x, z, y) * 100 cm, so X = east,
Y = south (north = -Y), Z = up. Tile actors sit at (100 cx, 100 cz, 0). Instance yaw = -ry.

## Materials (`Shaders/City/*.ush`, generated by `tools/export/gen_shaders.mjs` + `glsl2hlsl.mjs` from `src/world/*.js`)
- `M_CityFacade`: full port of `facade.js` FRAG_DECL (interior mapping from the interiors atlas, parallax window reveals,
  tripartite masonry zoning, sash / curtain / ribbon / deco window styles, storefronts + sign bands, roll-down shutters,
  AC units, grime decal sheet, rain streaks, soot, far-LOD box-filtered window pattern, night room lights via MPC `NightK`).
  Glass: the browser's coated-glass F0 is applied as metallic glass (BaseColor = F0 x tint, Metallic = glass weight), so
  Lumen reflections replace the browser's faked city reflection. Non-Nanite (Nanite quantises the data UVs).
- `M_CityDetail` (masked: fire-escape grating), `M_CityRoof`, `M_CityAsphalt`, `M_CitySidewalk`: ports of the matching browser shaders.
- `M_CityProp` (partmat.js port, per-instance tint in custom data), `M_CityVC` (vertex colour / atlas), `M_CityLeaves`.
- `MPC_City`: NightK, DnTime, InteriorGain, ShopGain, EmissiveScale.
- Include path `/Project/City/*.ush` = `unreal/WebHomage/Shaders/City` (UE maps `<project>/Shaders` to `/Project`).
